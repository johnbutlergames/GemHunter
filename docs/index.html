GemHunter

An AI-generated open world RPG

Every world is unique — and your choices leave a mark that can never be undone.

about

A world built by AI.

GemHunter is a browser-based pixel art RPG where Google Gemini generates a unique world every time you play, crafting a landscape description, generating pixel art through AI image generation, and extracting a color palette directly from that image to paint your map.

Each world is alive. The gems you're hunting are the lifeblood of the land you walk on. You can choose to explore peacefully, leaving every world intact. Or you can take the gems — and watch what happens on your way back out.

🌍
Procedural worlds
Walk off the edge of any map to discover a new biome. Up to 5 unique AI-generated worlds per run, each with its own palette and feel.
🎨
AI color extraction
Colors are pulled directly from each generated landscape image and used to paint the game world — grass, rock, sky and all.
💎
Five gems, five worlds
Each gem belongs to a world. Collect them all and return home through everything you've taken.
how it works

From prompt to playable world.

Every time you enter a new biome, Gemini runs behind the scenes to bring it to life.

01
Gemini describes the world

A Gemini model generates a rich biome description — the climate, flora, mood, and feeling of the place. This becomes the seed for everything else.

02
An image is generated

The description is turned into an image generation prompt and sent to Pollinations.AI, which returns a pixel art landscape of the biome.

03
Colors are extracted

Our code samples the image in horizontal strips (sky, horizon, midground, ground) and finds vivid accent colors.

04
Gemini paints the map

The palette is sent back to Gemini along with the biome description. It assigns colors to grass, ground, rock, plants, and special terrain, then the map is drawn and ready to be explored.

05
You decide what happens next

The world is yours. Explore, or hunt. But remember: your actions have consequences.

try it yourself

Get it running in four steps.

You'll need Node.js and a free Google Gemini API key.

01
Clone the repository
git clone https://github.com/yourusername/gemhunter.git then cd gemhunter
02
Install dependencies
Run npm install in the project root.
03
Add your Gemini API key
Get a free key at aistudio.google.com/app/apikey. Create a .env file and add GEMINI_API_KEY=your_key_here.
04
Start the game
Run npm run start and explore the world of GemHunter!
Check out our README.md for detailed installation instructions.
